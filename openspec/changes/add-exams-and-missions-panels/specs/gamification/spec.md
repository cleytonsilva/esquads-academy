## ADDED Requirements
### Requirement: Badge on final exam pass
Students who pass a final exam SHALL receive a badge.

#### Scenario: Grant exam pass badge
- WHEN a student passes the final exam for a course
- THEN the system SHALL grant the badge “Aprovado em Exame Final” if not already awarded

### Requirement: Badge on missions milestone
Students SHALL receive a badge when completing a milestone number of missions.

#### Scenario: Grant missions milestone badge
- WHEN a student completes 5 missions
- THEN the system SHALL grant the badge “Explorador de Missões” if not already awarded
